# VOCÊ PJ CONTABILIDADE — Documentação do Projeto

> Site institucional da VOCÊ PJ Contabilidade, desenvolvido com React + Vite + TypeScript + TailwindCSS.

---

## 🚀 Stack Tecnológica

| Tecnologia | Versão | Uso |
|---|---|---|
| React | 19.2.4 | Framework principal |
| TypeScript | ^5 | Tipagem estática |
| Vite | ^8 | Bundler e dev server |
| TailwindCSS | ^4 | Estilização |
| Framer Motion | ^12 | Animações e transições |
| Swiper | ^12 | Carrossel de depoimentos |
| React Bootstrap Icons | ^1.11 | Ícones |
| GSAP | ^3.15 | Animações avançadas |

## 📋 Histórico de Atualizações

### v1.3.0 — 2026-06-12
**Mobile Optimization + Logo + Refatoração de Seções**

#### 📱 Otimizações Mobile
- `Navbar`: Logo reduzida para `h-12` no mobile (`h-40` no desktop)
- `Hero`: Removida margem negativa `-mt-16` no mobile; espaçamento ajustado
- `Diferenciais`: Imagem com altura responsiva (`h-300px` mobile → `h-600px` desktop); badge posicionado sem overflow
- `Números`: Padding reduzido no mobile; números `text-4xl` no mobile
- `Depoimentos`: Padding vertical `py-16` no mobile
- `Processo`: Grid de 2 colunas no mobile
- `Formulário`: Campos telefone/email em 1 coluna no mobile (`grid-cols-1 sm:grid-cols-2`)
- `Footer`: Logo `h-24` no mobile; padding reduzido

#### 🖼️ Logo
- Arquivo renomeado de `logo sem fundo.png` → `logo-sem-fundo.png` (eliminação de espaços no nome)
- Logo inserida no **Navbar** (substituindo ícone "V" + texto)
- Logo inserida no **Rodapé** com filtro `brightness-0 invert` (branca sobre fundo escuro)
- Logo definida como **favicon** da aba do navegador (`index.html`)

#### 🏠 Hero
- Botão CTA "👉 Falar com um Especialista" restaurado no mobile
- Floating cards removidos do Hero (posicionamento absoluto eliminado)

#### 📊 Seção Números
- Cards com ícones ("+500 Empresas", "Atendimento Nacional", "Suporte Especializado", "Contabilidade Digital") movidos do Hero para o topo da seção Números
- Layout unificado: **Cards com ícones → Divisor → Estatísticas numéricas**

## 🎨 Design System

### Cores principais (definidas em `index.css`)
| Token | Uso |
|---|---|
| `--primary` | Azul escuro — fundo navbar, rodapé, botões |
| `--accent` | Dourado — destaques, ícones, CTA |
| `--secondary` | Tom intermediário — subtítulos |
| `--background` | Fundo principal da página |
| `--foreground` | Texto principal |
| `--muted` | Fundos de seções alternadas |
| `--border` | Bordas de cards |

### Fontes
- **Poppins** (Google Fonts) — 300, 400, 500, 600, 700
